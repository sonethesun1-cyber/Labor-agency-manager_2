# ລະບົບຈັດການແຮງງານ (Labor Agency Manager)

ແອັບຊ່ວຍຈັດການທຸລະກິດຮັບສະໝັກ/ຈັດສົ່ງແຮງງານລາວໄປເຮັດວຽກຢູ່ປະເທດໄທແບບຖືກກົດໝາຍ — ສ້າງຂຶ້ນໂດຍອີງໃສ່ 4 ວຽກຫຼັກຂອງທຸລະກິດ:

1. **ແຮງງານ (Workers)** — ຕິດຕາມຜູ້ສະໝັກແຕ່ລະຄົນຕັ້ງແຕ່ສະໝັກ → ອົບຮົມ → ກຽມເອກະສານ/ວີຊາ → ລໍຖ້າຈັດສົ່ງ → ເຮັດວຽກຢູ່ໄທແລ້ວ, ພ້ອມເຊັກລິສເອກະສານ (ໜັງສືຜ່ານແດນ, ກວດສຸຂະພາບ, ສັນຍາ, ວີຊາ, ໃບອະນຸຍາດເຮັດວຽກ).
2. **ບັນຊີການເງິນ (Finance)** — ບັນທຶກໜີ້ໄດ້ຮັບ (ລູກໜີ້ — ເງິນທີ່ຈະໄດ້ຮັບ) ແລະ ໜີ້ຕ້ອງຈ່າຍ (ເຈົ້າໜີ້ — ເງິນທີ່ຕ້ອງຈ່າຍອອກ) ແຍກລະອຽດ, ເຊື່ອມກັບແຮງງານແຕ່ລະຄົນໄດ້, ມີສະຫຼຸບຍອດຄ້າງຊຳລະ.
3. **ການອົບຮົມ (Training)** — ບັນທຶກຫົວຂໍ້/ວັນທີ ການອົບຮົມກ່ອນຈັດສົ່ງ, ເຊື່ອມກັບແຮງງານແຕ່ລະຄົນ ຫຼື ອົບຮົມລວມໄດ້.
4. **ສ້າງຄອນເທນ (AI Content Generator)** — ໃຊ້ Claude AI ຊ່ວຍຂຽນ caption ຮັບສະໝັກງານ ສຳລັບ TikTok ຫຼື Facebook ແບບພ້ອມໂພສ, ພ້ອມ hashtag ແລະ ໄອເດຍວິດີໂອ (ສຳລັບ TikTok).

ທຸກໜ້າເປັນພາສາລາວ, ອອກແບບໃຫ້ຄົນທຳມະດາໃຊ້ງານໄດ້ງ່າຍ (ບໍ່ຈຳເປັນຕ້ອງຮູ້ເລື່ອງໂປຣແກຣມ).

## ການຕິດຕັ້ງ (Local setup)

```bash
npm install
cp .env.example .env
npm start
```

ເປີດ browser ໄປທີ່ `http://localhost:3000`

## ຕັ້ງຄ່າ API Key (ສຳລັບສ້າງຄອນເທນ)

ໜ້າ "ແຮງງານ", "ບັນຊີການເງິນ", ແລະ "ການອົບຮົມ" ໃຊ້ໄດ້ທັນທີ ບໍ່ຕ້ອງຕັ້ງຫຍັງ. ສະເພາະໜ້າ "ສ້າງຄອນເທນ" ທີ່ຕ້ອງການ Anthropic API Key:

1. ໄປທີ່ [console.anthropic.com](https://console.anthropic.com) ສ້າງ API key
2. ເປີດແອັບ → ກົດ "⚙️ ຕັ້ງຄ່າ" → ວາງ API key → ກົດບັນທຶກ

ຄ່າໃຊ້ຈ່າຍແມ່ນຕາມການໃຊ້ງານຈິງຂອງ Anthropic (ແຕ່ລະໂພສທີ່ສ້າງ ເສຍຄ່າໃຊ້ຈ່າຍເລັກນ້ອຍ — ປະມານ 1-2 ເຊັນ).

## Deploy ຂຶ້ນ Render (ຟຣີ)

1. Push ໂຄດນີ້ຂຶ້ນ GitHub repo
2. ໄປທີ່ [render.com](https://render.com) → New → Web Service → ເລືອກ repo ນີ້
3. Build Command: `npm install`　/　Start Command: `npm start`
4. ໃນໜ້າ Environment ຕັ້ງຄ່າ `SITE_PASSWORD` ໃຫ້ (ແນະນຳຢ່າງແຮງ ເພາະແອັບນີ້ມີຂໍ້ມູນການເງິນ/ສ່ວນຕົວຂອງແຮງງານ — ຖ້າ deploy ຂຶ້ນອອນລາຍໂດຍບໍ່ຕັ້ງລະຫັດຜ່ານ, ໃຜມີລິ້ງກໍ່ເຂົ້າເບິ່ງຂໍ້ມູນໄດ້)
5. `ANTHROPIC_API_KEY` ສາມາດຕັ້ງຢູ່ນີ້ກໍ່ໄດ້ ຫຼື ຕັ້ງຜ່ານໜ້າ "⚙️ ຕັ້ງຄ່າ" ພາຍຫຼັງກໍ່ໄດ້

## ຂໍ້ມູນຖືກເກັບຢູ່ໃສ

ຂໍ້ມູນທັງໝົດ (ແຮງງານ, ບັນຊີ, ການອົບຮົມ, ປະຫວັດຄອນເທນ) ຖືກເກັບໄວ້ໃນໄຟລ໌ `data.json` ຢູ່ໃນໂຟນເດີໂຄດ. **ຂໍ້ສຳຄັນ:** ບາງ hosting ຟຣີ (ເຊັ່ນ Render free tier) ຈະລຶບໄຟລ໌ເວລາ redeploy — ຖ້າຢ້ານເສຍຂໍ້ມູນ, ຄວນ backup ໄຟລ໌ `data.json` ເປັນໄລຍະ ຫຼື ແຈ້ງຂ້ອຍໃຫ້ຊ່ວຍຕໍ່ກັບຖານຂໍ້ມູນຈິງ (ເຊັ່ນ Render Postgres ຟຣີ) ໃນພາຍຫຼັງ.

## ແຜນຂະຫຍາຍຕໍ່ (ຍັງບໍ່ໄດ້ເຮັດ — ບອກໄດ້ເລີຍຖ້າຢາກໄດ້)

ອັນນີ້ແມ່ນເວີຊັ່ນທຳອິດ (MVP) ຄົບທັງ 4 ໂມດູນທີ່ຮ້ອງຂໍ. ຄວາມສາມາດທີ່ສາມາດເພີ່ມຕໍ່ໄດ້ ຖ້າຕ້ອງການ:
- ສົ່ງແຈ້ງເຕືອນອັດຕະໂນມັດ (ຜ່ານ LINE/Telegram) ເມື່ອໜີ້ຄົບກຳນົດ ຫຼື ເອກະສານໃກ້ໝົດອາຍຸ
- ສົ່ງອອກ (export) ບັນຊີການເງິນເປັນ Excel/PDF ສຳລັບສົ່ງໃຫ້ນັກບັນຊີ
- ອັບໂຫລດຮູບ/ສະແກນເອກະສານຕິດກັບແຕ່ລະແຮງງານ
- ສ້າງຮູບປະກອບ (ບໍ່ແມ່ນແຕ່ captionໂຕໜັງສື) ສຳລັບໂພສ TikTok/Facebook ດ້ວຍ AI
- ຫຼາຍຜູ້ໃຊ້ (multi-user) ພ້ອມສິດທິ໌ແຕກຕ່າງກັນ

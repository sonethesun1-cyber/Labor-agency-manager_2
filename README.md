# ລະບົບຈັດການແຮງງານ (Labor Agency Manager)

ແອັບຊ່ວຍຈັດການທຸລະກິດຮັບສະໝັກ/ຈັດສົ່ງແຮງງານລາວໄປເຮັດວຽກຢູ່ປະເທດໄທແບບຖືກກົດໝາຍ. ລາຍຊື່ແຮງງານ/ວຽກຕົວຈິງແມ່ນເກັບຢູ່ໃນລະບົບ **KS Recruitment Agency** ຂອງເຈົ້າຢູ່ແລ້ວ — ແອັບນີ້ **ນຳເຂົ້າ (import)** ຂໍ້ມູນນັ້ນມາອ້າງອີງ ແລະ ເພີ່ມເຄື່ອງມືທີ່ KS ຍັງບໍ່ມີ:

1. **ບັນຊີການເງິນ (Finance)** — ແທັບຫຼັກ, ແບ່ງເປັນ 4 ສ່ວນຍ່ອຍ:
   - 💰 **ບັນຊີ** — ບັນທຶກໜີ້ໄດ້ຮັບ/ໜີ້ຕ້ອງຈ່າຍດ້ວຍມື, ເຊື່ອມກັບແຮງງານ (ທັງທີ່ເພີ່ມເອງ ຫຼື ຈາກ KS) ໄດ້
   - 📥 **ຈາກ KS** — ເບິ່ງລາຍຊື່ແຮງງານທີ່ນຳເຂົ້າຈາກ KS (ອ່ານຢ່າງດຽວ)
   - 🧮 **ຄິດໄລ່ຕາມ Lot** — ຄິດໄລ່ລາຍຮັບ/ລາຍຈ່າຍອັດຕະໂນມັດຕາມ Lot (ປ້ອນລາຄາ/ຄົນເອງ, ຈຳນວນຄົນຄຳນວນຈາກ KS ໃຫ້)
   - ⚠️ **ແຮງງານໜີ** — ບັນທຶກແຮງງານທີ່ສົ່ງໄປແລ້ວແຕ່ໜີ, ພ້ອມສ້າງໃບສັນຍານຳໜີ້ເປັນ PDF
2. **ການອົບຮົມ (Training)** — ບັນທຶກຫົວຂໍ້/ວັນທີ ການອົບຮົມກ່ອນຈັດສົ່ງ, ຄົ້ນຫາ-ເຊື່ອມກັບແຮງງານ (ທ້ອງຖິ່ນ ຫຼື ຈາກ KS) ຫຼື ອົບຮົມລວມໄດ້.
3. **ສ້າງຄອນເທນ (AI Content Generator)** — ໃຊ້ Claude AI ຊ່ວຍຂຽນ caption ຮັບສະໝັກງານ ສຳລັບ TikTok ຫຼື Facebook, ເລືອກຮູບແບບໄດ້ (ມາດຕະຖານ / ປະສົບການຈິງ / Before-After), ສ້າງໃຫ້ 3 ແບບທຸກຄັ້ງ ພ້ອມ hashtag, ໄອເດຍວິດີໂອ ແລະ ອາລົມສຽງ/ເພງແນະນຳ (ສຳລັບ TikTok).

ທຸກໜ້າເປັນພາສາລາວ, ອອກແບບໃຫ້ຄົນທຳມະດາໃຊ້ງານໄດ້ງ່າຍ (ບໍ່ຈຳເປັນຕ້ອງຮູ້ເລື່ອງໂປຣແກຣມ).

## ເຊື່ອມຕໍ່ກັບ KS Recruitment Agency (ລະບົບເກົ່າ)

ຖ້າເຈົ້າມີລະບົບ KS Recruitment Agency ຢູ່ແລ້ວ (ksrecruitmentagency.it.com) — ແອັບນີ້ສາມາດ **ນຳເຂົ້າ (import)** ຂໍ້ມູນແຮງງານ ແລະ ວຽກ ຈາກລະບົບນັ້ນໄດ້:

1. ເຂົ້າລະບົບ KS Recruitment Agency → ກົດ "ສຳຮອງຂໍ້ມູນ" → ໄດ້ໄຟລ໌ JSON
2. ເປີດແອັບນີ້ → "⚙️ ຕັ້ງຄ່າ" → ອັບໂຫລດໄຟລ໌ນັ້ນ → ກົດ "ນຳເຂົ້າ"

ຫຼັງຈາກນັ້ນ:
- ໜ້າ "ບັນຊີການເງິນ → 📥 ຈາກ KS" ສະແດງແຮງງານທັງໝົດທີ່ນຳເຂົ້າມາ (ອ່ານຢ່າງດຽວ — ແກ້ໄຂໄດ້ສະເພາະໃນລະບົບເກົ່າ)
- ໜ້າ "ບັນຊີການເງິນ → 🧮 ຄິດໄລ່ຕາມ Lot" ຈັດກຸ່ມແຮງງານຕາມ Lot ອັດຕະໂນມັດ, ແບ່ງ "ກຽມເດີນທາງ"/"ບໍ່ເດີນທາງ" ຈາກສະຖານະໃນ KS — ປ້ອນລາຄາ/ຄົນເອງ ແລ້ວລະບົບຄິດໄລ່ລາຍຮັບ-ລາຍຈ່າຍ-ລວມໃຫ້
- ໜ້າ "ບັນຊີການເງິນ → ⚠️ ແຮງງານໜີ" ສຳລັບແຮງງານທີ່ສົ່ງໄປແລ້ວແຕ່ໜີ — ບັນທຶກຕົວແທນ/ຄ່າປັບໄໝ ແລ້ວສ້າງ "ໃບສັນຍານຳໜີ້" ເປັນ PDF ພິມໄດ້ທັນທີ (ຕັ້ງຂໍ້ມູນບໍລິສັດໄວ້ລ່ວງໜ້າໃນໜ້າ "⚙️ ຕັ້ງຄ່າ" ເພື່ອໃຫ້ຂຶ້ນຫົວເອກະສານ)
- ໜ້າ "ການອົບຮົມ" ສາມາດເລືອກແຮງງານຈາກ KS ມາບັນທຶກການອົບຮົມນຳໄດ້ (ພິມຊື່ຄົ້ນຫາ)
- ໜ້າ "ສ້າງຄອນເທນ" ສາມາດເລືອກວຽກຈາກ KS ມາຕື່ມຂໍ້ມູນໃນແບບຟອມອັດຕະໂນມັດ (ຕຳແໜ່ງ, ເງິນເດືອນ, ເງື່ອນໄຂ, ເວລາເຮັດວຽກ ແລະອື່ນໆ)

ນີ້ແມ່ນ **ການນຳເຂົ້າທາງດຽວ (one-way)** — ຂໍ້ມູນຍັງຢູ່ຄົບໃນລະບົບ KS ເໝືອນເດີມ, ແອັບນີ້ພຽງແຕ່ເກັບ "snapshot" ໄວ້ອ້າງອີງ. ອັບໂຫລດໄຟລ໌ backup ໃໝ່ເວລາໃດກໍ່ໄດ້ທີ່ຢາກໃຫ້ຂໍ້ມູນທັນສະໄໝ (snapshot ເກົ່າຈະຖືກແທນທັງໝົດ). ບໍ່ຕ້ອງການ API ຫຼືລະຫັດຜ່ານຂອງລະບົບ KS ເລີຍ — ແຕ່ຖ້າພາຍຫຼັງຢາກໄດ້ແບບ sync ອັດຕະໂນມັດ (ບໍ່ຕ້ອງ export/import ເອງ) ກໍ່ເປັນໄປໄດ້ ເນື່ອງຈາກເປັນລະບົບທີ່ເຈົ້າ(ຫຼືທີມ)ສ້າງເອງ.

> 📌 ໝາຍເຫດ "ກຽມເດີນທາງ/ບໍ່ເດີນທາງ" ໃນ Lot calculator ແມ່ນແບ່ງອັດຕະໂນມັດຈາກຂໍ້ຄວາມສະຖານະໃນ KS (ເຊັ່ນ ຄຳວ່າ "ໜີ", "ຍົກເລີກ" ຈະນັບເປັນບໍ່ເດີນທາງ) — ຖ້າແບ່ງຜິດ ແກ້ສະຖານະໃນລະບົບ KS ແລ້ວນຳເຂົ້າໃໝ່.

**ຂໍ້ສຳຄັນດ້ານຄວາມປອດໄພ:** ຂໍ້ມູນທີ່ນຳເຂົ້າມາມີຂໍ້ມູນສ່ວນຕົວລະອຽດຂອງແຮງງານ (ເລກໜັງສືຜ່ານແດນ, ວັນເດືອນປີເກີດ, ຂໍ້ມູນສຸຂະພາບ). ຖ້າ deploy ແອັບນີ້ຂຶ້ນອອນລາຍ **ຕ້ອງ** ຕັ້ງ `SITE_PASSWORD` (ເບິ່ງຂັ້ນຕອນ deploy ຂ້າງລຸ່ມ) ບໍ່ດັ່ງນັ້ນໃຜມີລິ້ງກໍ່ຈະເຫັນຂໍ້ມູນນີ້ໄດ້.

## ການຕິດຕັ້ງ (Local setup)

```bash
npm install
cp .env.example .env
npm start
```

ເປີດ browser ໄປທີ່ `http://localhost:3000`

## ຕັ້ງຄ່າ API Key (ສຳລັບສ້າງຄອນເທນ)

ໜ້າ "ບັນຊີການເງິນ" ແລະ "ການອົບຮົມ" ໃຊ້ໄດ້ທັນທີ ບໍ່ຕ້ອງຕັ້ງຫຍັງ. ສະເພາະໜ້າ "ສ້າງຄອນເທນ" ທີ່ຕ້ອງການ Anthropic API Key:

1. ໄປທີ່ [console.anthropic.com](https://console.anthropic.com) ສ້າງ API key
2. ເປີດແອັບ → ກົດ "⚙️ ຕັ້ງຄ່າ" → ວາງ API key → ກົດບັນທຶກ

ຄ່າໃຊ້ຈ່າຍແມ່ນຕາມການໃຊ້ງານຈິງຂອງ Anthropic (ແຕ່ລະຄັ້ງສ້າງຄອນເທນຈະໄດ້ 3 ແບບພ້ອມກັນ, ເສຍຄ່າໃຊ້ຈ່າຍເລັກນ້ອຍຕໍ່ຄັ້ງ — ປະມານ 2-4 ເຊັນ).

## ໃບສັນຍານຳໜີ້ (PDF) — ຕັ້ງຂໍ້ມູນບໍລິສັດ

ກ່ອນສ້າງໃບສັນຍານຳໜີ້ຈາກ "ບັນຊີການເງິນ → ⚠️ ແຮງງານໜີ" ແນະນຳໃຫ້ຕັ້ງຂໍ້ມູນບໍລິສັດ (ຊື່, ທີ່ຢູ່, ເບີໂທ) ໄວ້ກ່ອນໃນໜ້າ "⚙️ ຕັ້ງຄ່າ" — ຂໍ້ມູນນີ້ຈະຂຶ້ນເປັນຫົວເອກະສານ ແລະ ລາຍເຊັນໃນ PDF ທີ່ສ້າງອອກມາ. ຖ້າບໍ່ຕັ້ງໄວ້ PDF ຈະຍັງສ້າງໄດ້ ແຕ່ຈະເປັນບ່ອນຫວ່າງໄວ້ຕື່ມມືຢູ່ແທນ. ຕົວອັກສອນລາວໃນ PDF ໃຊ້ຟອນ Noto Sans Lao (ແນບມານຳໃນໂຟນເດີ `fonts/`).

## Deploy ຂຶ້ນ Render (ຟຣີ)

1. Push ໂຄດນີ້ຂຶ້ນ GitHub repo
2. ໄປທີ່ [render.com](https://render.com) → New → Web Service → ເລືອກ repo ນີ້
3. Build Command: `npm install`　/　Start Command: `npm start`
4. ໃນໜ້າ Environment ຕັ້ງຄ່າ `SITE_PASSWORD` ໃຫ້ (ແນະນຳຢ່າງແຮງ ເພາະແອັບນີ້ມີຂໍ້ມູນການເງິນ/ສ່ວນຕົວຂອງແຮງງານ — ຖ້າ deploy ຂຶ້ນອອນລາຍໂດຍບໍ່ຕັ້ງລະຫັດຜ່ານ, ໃຜມີລິ້ງກໍ່ເຂົ້າເບິ່ງຂໍ້ມູນໄດ້)
5. `ANTHROPIC_API_KEY` ສາມາດຕັ້ງຢູ່ນີ້ກໍ່ໄດ້ ຫຼື ຕັ້ງຜ່ານໜ້າ "⚙️ ຕັ້ງຄ່າ" ພາຍຫຼັງກໍ່ໄດ້

## ຂໍ້ມູນຖືກເກັບຢູ່ໃສ

ຂໍ້ມູນທັງໝົດ (ແຮງງານ, ບັນຊີ, ການອົບຮົມ, ປະຫວັດຄອນເທນ, ຂໍ້ມູນທີ່ນຳເຂົ້າຈາກ KS) ຖືກເກັບໄວ້ໃນໄຟລ໌ `data.json` ຢູ່ໃນໂຟນເດີໂຄດ. **ຂໍ້ສຳຄັນ:** ບາງ hosting ຟຣີ (ເຊັ່ນ Render free tier) ຈະລຶບໄຟລ໌ເວລາ redeploy — ຖ້າຢ້ານເສຍຂໍ້ມູນ, ຄວນ backup ໄຟລ໌ `data.json` ເປັນໄລຍະ ຫຼື ແຈ້ງຂ້ອຍໃຫ້ຊ່ວຍຕໍ່ກັບຖານຂໍ້ມູນຈິງ (ເຊັ່ນ Render Postgres ຟຣີ) ໃນພາຍຫຼັງ.

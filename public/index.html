ບັນຊີການເງິນ

ຍັງບໍ່ໄດ້ນຳເຂົ້າຂໍ້ມູນຈາກ KS Recruitment Agency. ໄປທີ່ "⚙️ ຕັ້ງຄ່າ" ເພື່ອອັບໂຫລດໄຟລ໌ backup.

📌 ຂໍ້ມູນນີ້ແມ່ນ ອ່ານຢ່າງດຽວ (snapshot ຈາກການນຳເຂົ້າຄັ້ງລ່າສຸດ) — ແກ້ໄຂໄດ້ສະເພາະໃນລະບົບ KS Recruitment Agency ເທົ່ານັ້ນ.

ຄິດໄລ່ອັດຕະໂນມັດຈາກຂໍ້ມູນແຮງງານທີ່ນຳເຂົ້າຈາກ KS, ຈັດກຸ່ມຕາມ Lot. ຈຳນວນ "ກຽມເດີນທາງ"/"ບໍ່ເດີນທາງ" ແມ່ນແບ່ງອັດຕະໂນມັດຈາກສະຖານະຂອງແຮງງານໃນ KS (ຖ້າຜິດພາດ ກະລຸນາແກ້ໄຂສະຖານະໃນລະບົບ KS ແລ້ວນຳເຂົ້າໃໝ່). ກະລຸນາປ້ອນລາຄາຕໍ່ຄົນຂອງແຕ່ລະ Lot ເອງ.

ຍັງບໍ່ມີຂໍ້ມູນ Lot — ນຳເຂົ້າຂໍ້ມູນຈາກ KS ກ່ອນ (ໜ້າ "⚙️ ຕັ້ງຄ່າ").

ສຳລັບແຮງງານທີ່ສົ່ງໄປແລ້ວ ແຕ່ຕໍ່ມາ "ໜີ" ຫຼືບໍ່ປະຕິບັດຕາມສັນຍາ — ບັນທຶກຕົວແທນທີ່ຮັບຜິດຊອບ ແລະ ຄ່າປັບໄໝ, ແລ້ວສ້າງໃບສັນຍານຳໜີ້ເປັນ PDF ໄດ້ທັນທີ.

📥 ນຳເຂົ້າຂໍ້ມູນຈາກ KS Recruitment Agency

ເຂົ້າລະບົບ KS Recruitment Agency → ກົດ "ສຳຮອງຂໍ້ມູນ" ເພື່ອ download ໄຟລ໌ JSON → ອັບໂຫລດໄຟລ໌ນັ້ນຢູ່ນີ້. ຂໍ້ມູນແຮງງານ/ວຽກທີ່ນຳເຂົ້າຈະເປັນ ອ່ານຢ່າງດຽວ (ໃຊ້ອ້າງອີງໃນໜ້າ "ບັນຊີການເງິນ", "ການອົບຮົມ" ແລະ "ສ້າງຄອນເທນ"). ອັບໂຫລດໃໝ່ເວລາໃດກໍ່ໄດ້ທີ່ຢາກໃຫ້ຂໍ້ມູນທັນສະໄໝ — ຈະແທນຂໍ້ມູນເກົ່າທັງໝົດ.

⚠️ ຂໍ້ມູນທີ່ນຳເຂົ້າມີຂໍ້ມູນສ່ວນຕົວຂອງແຮງງານ (ເລກໜັງສືຜ່ານແດນ, ວັນເດືອນປີເກີດ ແລະ ອື່ນໆ) — ຖ້າຈະ deploy ແອັບນີ້ຂຶ້ນອອນລາຍ ໃຫ້ຕັ້ງ SITE_PASSWORD ຕາມທີ່ບອກໄວ້ໃນ README ສະເໝີ.
